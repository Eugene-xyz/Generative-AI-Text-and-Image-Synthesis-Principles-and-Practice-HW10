作業內容與證據

  • 6 份有效 ingest：S01–S06 均有原文、明列閱讀範圍、來源摘要與主題整合；超過至少 5 份要求。長手冊未宣稱全文精讀，補充規程未重複計篇數。ingest 登錄

  • 18 頁 HTML：沿已確認的大綱與整份內容稿，預估主講 18:20；含 18 組自製 SVG／31 個狀態、分步回合與三題測驗。保留補充、講解提示與逐頁來源。圖解素材紀錄
  • 先討論後生成：來源提案、graph、大綱 H1、全文 H2 依序確認；沒有在大綱尚未核准時直接做最終簡報。
  • 真實檢查紀錄：Chrome 三種視窗實測，182 項完整檢查及修正後 19 項局部複查通過；保留失敗、修正及代表畫面。最後一次資料夾整理與網站路徑複查見 整理紀錄。

高分項目已有對應證據，實際成績仍由教授判定。正式繳交前，填好「學校 學號 系級 姓名 主題」，將公開簡報、Wiki 與繳交總覽連結交到課程平台。試講時間與真實初學者理解測試尚未執行，可作為進一步改善。

使用方式

  • 前後頁按鈕、←／→、Page Up／Page Down 翻頁；Home／End 到首頁／末頁；目錄可跳頁。
  • 點「展開補充」自讀，點「講解提示」看講者備註；展開後可向下捲動。
  • 點圖放大；圖下小箭頭只換圖解步驟。第 04、06、10、16 頁有多個狀態。
  • 第 17 頁可選答案、顯示理由及回看。Tab、Enter／空白鍵支援控制項，Esc 關閉對話框。
  • 本機核心圖文與導覽可離線使用；開啟官方來源網站需網路。搬移時請保留整個資料夾的相對位置。

維護

一般瀏覽及 Pages 部署直接使用已生成檔案。修改知識或簡報時，先改 wiki、slides/content.md 或來源對照，再重建。

npm install
npm run build
python -m pip install -r requirements.txt
npm run check:content
npm run check:wiki
npm run check:browser -- new-check-name

工具及瀏覽器安裝細節見 GITHUB.md。自動檢查只輔助結構、顯示與操作，不能代替排球規則和圖解語意核對。verify_review.py 是「正式入庫前」的歷史檢查工具，不應拿來判定目前成果。

S01–S06 原文著作權屬各來源機構／作者；本專案以自寫摘要與自製圖解教學，沒有替第三方原始資料宣告新授權。來源與適用範圍見各來源頁；尚待釐清事項保留在 issues。
